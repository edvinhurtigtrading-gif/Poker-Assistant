# Poker Assistant v0.1

Första webbversionen av Poker Assistant.

## Funktioner
- 6-max pokerbord
- Hero sitter alltid visuellt längst ned
- Dealer-knappen roterar mellan händer
- BTN / SB / BB / UTG / HJ / CO räknas automatiskt
- Hero-positionen uppdateras automatiskt
- Next hand / Previous hand
- Lokal sessionslagring i webbläsaren
